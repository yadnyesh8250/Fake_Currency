Examiner Viva Q&A

Q1: "You bring a ₹500 note and the program says ₹500. I already know it's a 500 note! What did YOUR algorithm actually do?"

Defense: RupeeVision is an explainable computer vision system designed for IVP education. It applies 10 verifiable mathematical transformations:

  • Pre-flight IQA: Computes Laplacian variance σ²(∇²I) for blur, mean intensity μ for exposure, and clipped glare detection.
  • Spatial Filtering: 2D Gaussian convolution attenuates sensor noise.
  • CLAHE: Boosts micro-printing and watermarks across 8×8 tiles.
  • Perspective Homography: Calculates 3×3 matrix H to unwarp tilted notes.
  • Feature Matching: ORB keypoints + BEBLID descriptors verified by Lowe's Ratio (d₁/d₂ < 0.75) and RANSAC inlier consensus.
  • RBI Security: Audits security thread gradient, watermark window, intaglio texture, and specimen stamps.
Q2: "Why not use a Deep Learning model like YOLOv8 or MobileNet?"
  • Deterministic Rejection: Classical IVP uses RANSAC geometric consensus. No hallucination — outputs 'Unrecognized' when evidence is insufficient.
  • Sub-second Latency: Runs in ~100–300ms on basic CPUs without GPU.
  • Mathematical Transparency: Every step (Sobel gradients, homography matrix, Hue correlation) is backed by calculus and linear algebra.
Q3: "Can any software detect counterfeit currency with 100% certainty using a webcam?"

No. Physical currency has security layers invisible to 8-bit RGB sensors:

  • UV Fluorescent Fibers: Need UV-A 365nm illumination.
  • Magnetic Ink: Requires magnetic inductive heads.
  • Intaglio Relief: Requires capacitance or laser profilometry.

10-Stage Pipeline Mathematics

1. Gaussian Smoothing Filter
G(x, y) = (1 / 2πσ²) · e^(-(x² + y²) / 2σ²)
5×5 kernel suppresses sensor noise and paper grain.
2. Canny Edge Detection & Sobel Gradients
G = √(Gx² + Gy²), θ = arctan(Gy / Gx)
Non-maximum suppression + dual-threshold hysteresis (50/150).
3. Polygon Approximation (RDP)
ε = 0.02 · Perimeter(Contour)
Simplifies curves into 4-corner quadrilaterals.
4. Projective Homography
[x', y', 1]ᵀ ~ H · [x, y, 1]ᵀ, H ∈ ℝ³ˣ³
8-DOF transform warps skewed banknote to fronto-parallel rectangle.
5. Lowe's Ratio Test
||d_best|| / ||d_second_best|| < 0.75
Eliminates ambiguous descriptors by Hamming distance ratio.
6. Laplacian Sharpness Variance
σ²(∇²I) = (1/N) Σ[∇²I(x,y) − μ]²
Quantifies optical focus via second-order spatial derivative variance.

METHODOLOGY

RupeeVision — Automated Currency Recognition System

An Image & Video Processing (IVP) mini-project demonstrating classical computer vision techniques for Indian banknote denomination recognition, pre-flight image quality assessment, and visual consistency verification using OpenCV, NumPy, and Flask.

10-Stage IVP Pipeline

  • Stage 1: Image Acquisition & Decoding
  • Stage 2: Aspect-Ratio Preserving Resizing (target 800px width)
  • Stage 3: Grayscale Conversion (BT.601)
  • Stage 4: Gaussian Filtering (5×5, σ auto)
  • Stage 5: CLAHE Contrast Enhancement (clip=2.5, 8×8 grid)
  • Stage 6: Canny Edge Detection (50/150, L2 gradient)
  • Stage 7: Contour Detection & Corner Localization (RDP ε = 0.02·P)
  • Stage 8: Perspective Correction (Homography H)
  • Stage 9: ORB/BEBLID Feature Matching + Lowe's Ratio + RANSAC
  • Stage 10: Multi-Factor Authenticity & RBI Security Inspection

Scientific Honesty

This system performs visual consistency verification using standard 8-bit RGB imagery. It does not certify legal authenticity. UV fluorescent fibers, magnetic ink, and tactile intaglio relief require specialized physical sensors unavailable to consumer cameras.

Technology Stack

Python · Flask · OpenCV (cv2) · NumPy · HTML/CSS/JS · ORB · BEBLID (contrib) · RANSAC · CLAHE
